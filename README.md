🎮 PUBG Mobile AI Analyst – Erangel

An experimental AI-powered project focused on understanding PUBG Mobile gameplay through computer vision, machine learning, and Large Language Models (LLMs).

The project explores how AI can interpret the Erangel map, identify map-related visual information, and build the foundation for an intelligent PUBG Mobile gameplay analyst.

🚀 Project Overview

The goal of this project is to develop an AI analyst that can help PUBG Mobile players understand their gameplay, map positioning, and strategic decisions.

Using computer vision and LLM technologies, this project explores:

Map Intelligence: Processing and analyzing PUBG Mobile Erangel map images.

Object Detection: Using YOLO26 to detect and identify visual objects in map images.

Deep Learning: Experimenting with PyTorch and Ultralytics for model training and inference.

LLM Integration: Connecting locally hosted language models through Ollama.

Gameplay Analysis: Building a foundation for future match analysis and strategic insights.
